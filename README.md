# chat-voice-skill

> 用 **二十余万条真实微信聊天记录**提炼出来的语气克隆 skill。装进 [OpenCode](https://opencode.ai) 后，AI 能用你的语气帮你回消息、写通知、拟邮件。

本仓库是**脱敏公开版**：只保留语气规则和匿名化后的语料，不含任何真实人名、昵称、地名、学校、公司、班级、日期、联系方式。原始聊天记录永远不离开本地。

## 它能干什么

贴一段聊天 + 一句"用我的语气回"，AI 会：

1. 判断沟通对象类型（老师？HR？损友？闺蜜？家人？）
2. 按对应场景的语气规则生成回复
3. 默认输出成微信消息流：多条短消息、每条一行，还原真人拆条节奏

覆盖 8 种场景：

| 场景 | 语气 |
| --- | --- |
| 老师 / 导员 / 上级 | 礼貌闭环体：您 + 委婉请求 + [Rose] 刷屏 |
| HR / 客户 / 职场 | 客气轻商务体：口语确认 + 关键节点切书面语 |
| 同学 / 社团协调 | 直接办事体：@点名 + 要不 + #接龙 |
| 亲密好友 | 损友直给体：白字梗全开 + 交易玩笑 |
| 闺蜜 / 情感支持 | 温柔军师体：先探情绪 + 沉没成本式分析 |
| 游戏群 / 水群 | 抽象整活体：小剧场 + 客服模仿 + 发疯文学 |
| 家人 | 极简报平安体：叠词 + 关键词式回答 |
| 商家 / 陌生人 | 客气轻商务简化版：谁-事-结果一句话 |

核心风格：碎片化拆条（每条 2~12 字）、白字谐音梗（豪 / 彳亍 / 蚌埠住 / 我勒个豆）、中英混用（okok / btw / lets make a deal）、括号拖尾"、复读叠词、自嘲先行。

## 安装

**克隆进全局 skills 目录（推荐）**

```sh
git clone https://github.com/<你的用户名>/chat-voice-skill ~/.config/opencode/skills/chat-voice
```

Windows PowerShell：

```powershell
git clone https://github.com/<你的用户名>/chat-voice-skill "$env:USERPROFILE\.config\opencode\skills\chat-voice"
```

> 克隆后的文件夹名就是 skill ID（这里是 `chat-voice`），repo 叫什么随意。

更新：`git -C ~/.config/opencode/skills/chat-voice pull`

**或者手动安装**：把 `SKILL.md` 和 `references/` 整个复制到 `~/.config/opencode/skills/chat-voice/` 下即可。

## 使用

- 自动触发：对话里说"用我的语气回这条消息""模仿我说话""帮我拟一条给我导师的消息"
- 显式调用：`@chat-voice`

验证：新开一个 OpenCode 会话，输入 `@chat-voice`，能加载即安装成功。

## 这个 skill 是怎么做出来的

1. 用本地导出工具把微信文本记录导成 txt / jsonl（全程本地、不联网）
2. 按会话场景分组，采样"我"的消息（每场景 100~250 条）
3. 用便宜模型（如 DeepSeek Flash）并行跑 5 个子代理，每人产出一份场景风格分析：称呼 / 口头禅 / 句式 / 表情习惯 / do & don't
4. 人工汇总提炼成 `SKILL.md`（通用铁律 + 场景路由），真实例句沉淀进 `references/corpus.md`
5. 全量脱敏检查后发布

## 克隆你自己的语气

Fork 之后替换两处：

1. `SKILL.md` 第 1 节「人设底料」：换成你的身份、爱好、性格底色（只用于选词玩梗，别放隐私）
2. `references/corpus.md`：换成你自己聊天记录里的原声例句（建议每场景 20+ 条），发布前做一遍脱敏

通用铁律和场景路由跟你的风格不一样的话，直接改对应小节。八个场景不一定都留，按你的社交面删减。

## 脱敏说明

本仓库发布前已做：

- 真实人名 / 昵称 → 角色称呼（老师、导员、同学、室友、学长、HR、客户……）
- 地名 / 校区 / 楼栋 → 泛化表述
- 学校 / 公司 / 班级 / 日期 / 手机号 / 邮箱 / 住址 → 占位符【】或删除
- 涉及第三者隐私的内容（病情细节、聊天对象的个人信息）直接删除

发布你的版本前，建议照此再过一遍，并搜一遍手机号、邮箱、学号、地址等关键词。
