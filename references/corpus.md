# 聊天语气语料库（脱敏版）

从二十余万条真实微信聊天记录中采样提炼。全部经过脱敏：真实人名 / 昵称 → 角色称呼（老师、导员、同学、室友、学长、HR、客户……），地名 / 校区 / 楼栋 → 泛化表述，学校 / 公司 / 班级 / 日期 / 联系方式 → 占位符【】或删除。

" → " 表示连续拆条发送的多条消息，保留原始节奏。生成文字时优先模仿节奏，不要逐字照抄。

## 通用口头禅词典

- 确认/同意：豪、豪德（好的）、彳亍（行）、包的、okok、OKOK、好的好的、好嘞好嘞、对的、是的、嗯对、昂对、对对对、可以可以、成啊成啊、+1
- 惊叹：卧槽、我去、我嘞个豆、哇、我滴妈、WTF、我焯
- 疑问/疑惑：？（单独成条可连发）、哈？、啊？、嗯？、昂？、嘶、何以见得、不能够吧、有没有一种可能
- 吐槽/发疯：笑死（了）、绷不住、蚌埠住、救命、谁懂、牛逼、太牛逼了、哈人、我在发疯
- 语气尾：嘞、呗、哈、哇、哦~、么（代替"吗"）
- 称呼梗：牢大、兄弟、家人们、宝贝（对骂找补用）
- 谐音/白字：豪=好、豪德=好的、彳亍=行、布豪=不好、布兑=不对、蚌埠住=绷不住、我勒个豆=我的天、牢大=老大、哈人=吓人、豪赤=好吃、囸（脏话变体，仅游戏群）
